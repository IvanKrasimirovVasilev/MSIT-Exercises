Flask CRUD REST API

This project is a simple REST API for practicing Flask and the HTTP methods GET, POST, PUT, PATCH, and DELETE.

Users

Each user has three properties:

{
    "id": 1,
    "username": "alice",
    "email": "alice@email.com"
}

API Endpoints

Method Endpoint Description
GET /users Get all users
GET /users/<id> Get one user by ID
POST /users Create a new user
PUT /users/<id> Update the complete user
PATCH /users/<id> Update only selected user fields
DELETE /users/<id> Delete a user

GET

GET is used to retrieve data without changing it. 

GET /users

Returns all users.

GET /users/2

Returns the user with ID 2.

POST

POST is used to create a new user. 

POST /users

{
    "username": "ivan",
    "email": "ivan@email.com"
}

The API checks that username and email are provided and that they do not already exist.

A successfully created user returns 201 Created.

PUT

PUT is used to update an existing user. In this project both username and email are required. 

PUT /users/2

{
    "username": "robert",
    "email": "robert@email.com"
}

PATCH

PATCH is used to update only selected fields. Unlike PUT, it is not necessary to send all user data. 

PATCH /users/2

{
    "email": "bob.new@email.com"
}

Only the email is changed. The username remains unchanged.

DELETE

DELETE removes a user. 

DELETE /users/2

If the user does not exist, the API returns 404 Not Found.

HTTP Status Codes

Status Meaning
200 OK The request was successful
201 Created A new resource was successfully created
400 Bad Request The request contains invalid or missing data
404 Not Found The requested user does not exist
409 Conflict The username or email already exists

Testing with curl

Get all users:

curl.exe http://127.0.0.1:5001/users

Create a user:

curl.exe -X POST http://127.0.0.1:5001/users -H "Content-Type: application/json" -d '{\"username\":\"ivan\",\"email\":\"ivan@email.com\"}'

Update only the email:

curl.exe -X PATCH http://127.0.0.1:5001/users/2 -H "Content-Type: application/json" -d '{\"email\":\"new@email.com\"}'

Delete a user:

curl.exe -X DELETE http://127.0.0.1:5001/users/2
